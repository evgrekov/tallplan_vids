# Новые форматы (по разбору GoTall / Tallify / Taller)

Общее для всех: хук — вопрос про самого зрителя; приложение — ответ на этот вопрос; 12–20 с; безопасные зоны (подписи ≥270 px сверху, ничего важного ниже 0.76H, текст ≤80% ширины); в конце пэкшот TallPlan + «GET YOUR / PERSONAL ROUTINE».

## 1. Таблица роста по возрасту → квиз (`quiz.py quiz/chart.json`)
- 0–7.5 с: фото подростка в кадре, мягко качается в бит трека (без дрожи). Сверху хук «ARE YOU TALL / FOR 14?». На кадре всплывает карточка «AVERAGE HEIGHT · BOYS» со строками 13–17 лет (средние CDC), строка нужного возраста подсвечена мятным.
- 7.5 с: телефон въезжает снизу, подпись «TAKE THE QUIZ TO FIND / YOUR HEIGHT POTENTIAL».
- Экраны квиза в стиле приложения: возраст → рост → рост папы → рост мамы (цифры «печатаются»).
- Результат: реальный экран Growth из TallPlan (Adult height 6'2").
- Без голоса, только музыка. Новый ролик = другой возраст/пол в JSON.

## 2. Сетка 2×2 «glow up / как выглядеть выше» (`grid.py grid/glowup.json`)
- Слайд-шоу из 2–3 слайдов, на каждом заголовок и 4 фото с подписями (сетка 2×2).
- Слайд 1 — «как выглядеть выше» (осанка, посадка одежды, обувь, стрижка), слайд 2 — «как дорасти до максимума» (сон, белок, турник, спорт).
- Смена слайдов по биту, последний слайд без заголовка под пэкшотом.
- Серия: меняем тему (лицо, осанка, стиль, спорт) — формат узнаваемый.

## 3. Прогноз по чужим цифрам (`quiz.py quiz/comment.json`)
- 0–7 с: фото + пузырь комментария «14, 5'8, dad 6'1, mom 5'6 — how tall will I be?» и надпись «DROP YOUR NUMBERS».
- Дальше те же цифры вбиваются в квиз → результат.
- Пока своих комментариев нет — пузырь подписан как пример (@your_name), без выдачи за реальный отзыв. Потом подставляем реальные.

## 4. «Признаки, что ты ещё растёшь» (`char.py` с брифом)
- Маскот + голос + субтитры по словам: хук «3 signs you're still growing» → признаки (обувь мала, хочется спать и есть, ноют колени по ночам, ломается голос) → «точнее покажет только трекинг» → TallPlan.
- Мягкие формулировки: «обычно», «часто», без медицины и обещаний.

## 5. «Рост мамы → твой вероятный рост» (`quiz.py quiz/mom.json`)
- Вариант формата 1: хук «YOUR MOM IS 5'6\"?», таблица «MOM'S HEIGHT → SON'S LIKELY HEIGHT» по классической формуле от роста родителей (папа взят средний, 5'9"), подсветка строки.
- Дальше квиз → результат, как в формате 1.
